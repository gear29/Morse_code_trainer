This is a led morse code trainer that will have two buttons to show . and - and then will illuminate the led corresponding to a letter then put that on the screen 
This works by using 2 buttons going into a ras pi which computes the input and turns it into a output going into the display or one of the 4 led controlers
They then output the signal into one of 30 led's two of which are for testing in the code
